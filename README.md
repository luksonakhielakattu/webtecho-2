# 🏍️ Bike Showroom Website

## 📌 Project Overview
The Bike Showroom Website is a simple HTML5-based web application that allows customers to register their details and book a visit to a bike showroom. The project demonstrates the use of various HTML5 form elements along with basic CSS styling to create a clean and user-friendly booking form.

## ✨ Features
- Customer Name input
- Email Address input
- Phone Number input
- Age validation
- Preferred Visit Date selection
- Gender selection using radio buttons
- Bike Brand selection using checkboxes
- Bike Model selection using a dropdown menu
- Address input using textarea
- Preferred Bike Color picker
- Driving License file upload
- Budget Range slider
- HTML5 form validation
- Submit and Reset buttons
- Responsive and simple user interface using CSS

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Alternatively, run the project using the **Live Server** extension in Visual Studio Code.
